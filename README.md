# 五子棋

单机人机五子棋小游戏。规则为普通五子棋（无禁手），竖屏对局布局，支持闯关与自由对战。

可在浏览器里玩，也可以用 Electron 打成 Windows 安装包。

仓库：https://github.com/luokei88888-lgtm/Gomoku-master

---

## 这是什么

这是一款面向休闲游玩的 **15×15 五子棋**：你执一方，电脑执另一方。黑棋始终先手，任意方向连成五子即胜，没有连珠禁手。

游戏提供两种玩法：

| 模式 | 说明 |
|------|------|
| **闯关模式** | 共 30 关，由易到难。通关解锁下一关，每 10 关获得称号。 |
| **自由对战** | 自选简单 / 中等 / 困难，可反复对局、复盘。 |

没有账号、没有联网对战。设置、闯关进度和对局记录都保存在本机。

---

## 规则

- 棋盘 **15×15**，落子在交叉点。
- **黑棋先手**，双方轮流下一子。
- 横、竖、斜任意方向 **连成 5 子** 即获胜。
- **无禁手**：双活三、长连等都允许。
- 棋盘下满且无人连五，判 **和棋**。

闯关模式固定你执黑（先手）。自由对战可在设置里选择先手或后手。

---

## 怎么玩

1. 打开游戏后进入首页。
2. 点 **闯关模式** 选关，或点 **自由对战** 直接开下一局。
3. 在交叉点点击落子，电脑会自动回应。
4. 先连成五子者获胜。

### 首页

- **闯关模式**：进入关卡地图。
- **自由对战**：按当前设置立即开局。
- **游戏设置**：难度、阵营（先手/后手）、主题皮肤。
- **历史对局**：查看最近记录并复盘（没有记录时按钮不可用）。
- **音效开关**：开/关程序化音效。

设置里的难度和阵营主要影响 **自由对战**。闯关每关的电脑强度由关卡本身决定。

### 对局界面

布局为上中下三层：顶栏显示你与电脑、当前回合；中间是占满宽度的棋盘；底栏是操作按钮。

| 按钮 | 作用 |
|------|------|
| 退出 | 闯关回到地图，自由对战回到首页。终局后会暂时禁用，避免跳过结算。 |
| 悔棋 | 撤回你和电脑各一步（若只有一步则撤一步）。电脑思考中或对局已结束时不可用。 |
| 提示 | 标出当前推荐落点。 |
| 重开 | 重开本局。 |
| 设置 | 音效、切换主题、认输。 |

### 结算

- 胜利 / 惜败 / 和棋；闯关通关第 30 关会显示「通关！」。
- 闯关胜利会给本关打星，并可进入下一关、再试一次或返回地图。
- 自由对战可再来一局、复盘或返回首页。

## 闯关模式

共 **30 关**，必须按顺序解锁（通关第 N 关后解锁第 N+1 关）。地图一页展示全部关卡。

### 难度曲线

| 关卡 | 难度 | 说明 |
|------|------|------|
| 1–10 | 简单 | 入门试炼。电脑会挡冲四、拦活三，偶尔在不关键处下得松一些。 |
| 11–20 | 中等 | 进阶挑战。搜索更深，不再故意走软手。 |
| 21–30 | 困难 | 高手对决；28–30 关为终极试炼。 |

电脑在任何难度下都 **不会漏掉立刻能赢的棋，也不会故意不挡你的冲四**。

### 星级

通关至少得 1 星。总手数越少星越多（双方落子合计）：

| 星级 | 条件 |
|------|------|
| ★☆☆ | 通关 |
| ★★☆ | 总手数 ≤ 36 |
| ★★★ | 总手数 ≤ 24 |

同一关可重复挑战，只保留历史最高星。

### 称号

每通关 10 关获得一次称号，首次达成时结算页会显示祝贺文案。重复打同一关不会再弹。

| 关卡 | 称号 |
|------|------|
| 第 10 关 | 新锐棋手 |
| 第 20 关 | 闯关达人 |
| 第 30 关 | 棋圣传说 |

地图顶部会显示当前最高称号。

## 主题

四套休闲风格皮肤，棋子是程序绘制的卡通形象，可在首页设置或对局设置中切换。

| 主题 | 双方形象 |
|------|----------|
| 数码大冒险（默认） | 亚古兽 vs 滚球兽 |
| 光之英雄 | 巴尔坦 vs 奥特曼 |
| 糖果派对 | 葡萄软糖 vs 奶油糖 |
| 花园鲜果 | 蓝莓 vs 草莓 |

这些造型为自行绘制的示意头像，相关 IP 属于对应权利方，**仅供个人学习，不要公开发售或商用**。

## 本地数据

全部写在浏览器（或 Electron 窗口）的 `localStorage`，不上传服务器。

| 内容 | 说明 |
|------|------|
| 游戏设置 | 主题、自由对战难度、先手/后手、音量 |
| 闯关进度 | 已解锁关卡、每关最高星、已获得称号 |
| 对局记录 | 最近最多 30 盘，可复盘 |

清除站点数据或重装后进度会丢失。

## 运行与打包

需要 Node.js（建议 18+）。

```bash
npm install
npm run dev          # 浏览器调试，默认 http://localhost:5174
npm test             # 单元测试
npm run build        # 构建网页资源到 dist/
npm run app:start    # 先 build，再启动 Electron 窗口
npm run app:dist     # 产出 Windows 安装包 release/Gomoku-Setup-1.0.0.exe
```

安装包为 NSIS，可改安装目录，并创建桌面与开始菜单快捷方式。

## 技术结构

Vite + TypeScript + Phaser 3，可选 Electron 桌面包。

```
src/
  core/          棋盘、胜负、悔棋
  ai/            评估与搜索（人机）
  data/          关卡、称号
  game/          场景：首页 / 地图 / 对局 / 结算 / 复盘 / 历史
  storage/       设置、进度、对局记录
  art/           主题与棋子贴图
  ui/            布局与控件
electron/        Electron 主进程
tests/           Vitest
```

身份与进度都在本地完成，不信任任何外部传入的用户 ID。密钥不会进仓库。
