# 五子棋

竖屏人机五子棋。普通规则（无禁手），闯关 + 自由对战，多主题，支持悔棋、提示与复盘。

支持浏览器游玩，也可以用 Electron 打成 Windows 安装包。

## 功能

- **闯关模式**：30 关，难度由易到难；每 10 关获得称号
- **自由对战**：简单 / 中等 / 困难
- **执黑或执白**：黑棋始终先手
- **普通五子棋**：15×15，连五即胜，无禁手
- **悔棋 / 提示 / 认输 / 重开**
- **四套主题**：糖果派对、花园鲜果、数码大冒险、光之英雄
- **本地对局记录**（最多 30 盘）与复盘
- **程序化音效**，可静音
- **Windows 安装包**：NSIS，桌面快捷方式

## 怎么玩

1. 首页进入「闯关模式」或「自由对战」。
2. 在交叉点落子；电脑会自动回应。
3. 先连成五子者获胜；棋盘下满为和棋。

## 开发

```bash
npm install
npm run dev          # 浏览器调试 http://localhost:5174
npm test             # 单元测试
npm run build        # 构建网页资源
npm run app:start    # 需先 build，再开 Electron
npm run app:dist     # 产出 release/Gomoku-Setup-1.0.0.exe
```
